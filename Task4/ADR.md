### <a name="_uanumrh8zrui"></a>**Дата: 09.03.2025**
### <a name="_3bfxc9a45514"></a>**Функциональные требования**

|**№**|**Действующие лица или системы**|**Use Case**|**Описание**|
| :-: | :- | :- | :- |
|1|Сотрудник кол-центра|Просмотр актуальных ставок по депозитам|Сотрудник кол-центра видит текущие ставки для консультации клиентов|
|2|Система кол-центра|Получение актуальных ставок из АБС|Система кол-центра автоматически получает ставки из АБС через файловый обмен|
|3|Партнёрский кол-центр|Получение актуальных ставок через файлы|Ставки передаются в партнёрский кол-центр в виде файлов (например, CSV) через SFTP|
|4|АБС|Генерация файлов с актуальными ставками|АБС формирует файлы с актуальными ставками для передачи в кол-центр и партнёрский кол-центр|
### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

|**№**|**Требование**|
| :-: | :- |
|1|Файлы с актуальными ставками должны обновляться ежедневно|
|2|Защита файлов при передаче через шифрование|
|3|Доступность ставок для сотрудников кол-центра в течение 5 минут после обновления|
|4|Минимизация ручного труда при формировании и передаче файлов|
|5|Логирование процесса передачи файлов для аудита|
### <a name="_qmphm5d6rvi3"></a>**Решение**

![alt_text](C4Model.png)

* Минимизация рисков:
    + Использование файлового обмена вместо API для партнёрского кол-центра снижает сложность интеграции
    + Шифрование файлов через SFTP обеспечивает безопасность данных
* Автоматизация процессов:
    + Автоматическая генерация файлов в АБС уменьшает ручной труд
    + Ежедневное обновление файлов гарантирует актуальность данных
* Гибкость и масштабируемость:
    + Поддержка как внутреннего, так и партнёрского кол-центра позволяет масштабировать поддержку клиентов
* Удобство использования:
    + Интеграция файлов с системой кол-центра упрощает доступ к данным для сотрудников.
### <a name="_bjrr7veeh80c"></a>**Альтернативы**
* Использование API для партнёрского кол-центра:
    + Плюсы: Более современный подход, быстрое обновление данных
    + Минусы: Высокая сложность реализации, отсутствие технической возможности у партнёра
* Ручная передача файлов:
    + Плюсы: Простота реализации
    + Минусы: Высокий риск ошибок, увеличение операционных издержек

**Недостатки, ограничения, риски**

* Недостатки:
    + Зависимость от SFTP-сервера для передачи файлов
    + Возможные задержки при обновлении данных
* Ограничения:
    + Отсутствие API-интеграции с партнёрским кол-центром
    + Вертикальное масштабирование АБС ограничивает производительность
* Риски:
    + Недостаточная защита файлов при передаче
    + Возможные сбои в работе SFTP-сервера
